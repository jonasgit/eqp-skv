Ett verktyg för att översätta vad EquatePlus och Nordnet redovisar till vad Skatteverket vill ha. Både som python och Go-lang.

Ladda ner filer från EquatePlus:
PortfolioDetails*.xlsx
CompletedTransactions*.xlsx
Sammanfattning av inköpscykel*.csv

Ladda ner fil från Nordnet:
Nordnet*.csv

Kör programmet i samma katalog som filerna ligger.
